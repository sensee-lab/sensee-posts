# sensee-posts

Espelho automático das imagens finais publicadas no Instagram da Sensee.

Gerenciado pela Routine diária do repositório
[`sensee-content`](https://github.com/sensee-lab/sensee-content) — **não
editar manualmente**. Cada post publicado tem sua pasta em `posts/<slug>/`
com os JPEGs usados como fonte para a Meta Graph API.
